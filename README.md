# Prysm Resources

This repository serves as a CDN (Content Delivery Network) for Tor binaries across different platforms for the Prysm P2P Chat app.

## Structure

The repository contains Tor binaries organized by:
- Operating System (Windows, Linux, macOS)

## Disclaimer

This repository only hosts official (or self-compiled without changing) Tor binaries.
This repo is updated only by project maintainer for security purposes
